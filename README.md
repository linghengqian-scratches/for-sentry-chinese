# for-sentry-chinese

## Notes

- This repository serves https://github.com/getsentry/sentry/issues/123993 and maintains the Simplified Chinese translation for the Sentry WebUI.
- The IntelliJ IDEA `.idea/` directory and `*.iml` module files are ignored by `.gitignore` and must not be committed.
- Line endings are enforced via `.gitattributes`: all text files use Linux LF (`\n`); never commit CRLF line endings.
